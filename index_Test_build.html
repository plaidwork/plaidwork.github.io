更新日志

v1.3.6F

修复云端默认展示图在地址可用时仍可能不显示的问题，并完善慢速加载、旧设置兼容和自动恢复体验。

2 种模式默认增强 / 完全自定义
本地备份JSON 导入 / 导出
Hero 展示图云端 / URL / 本地

个性化导航

  • 新增“默认配置 + 本地自定义”和“完全自定义”两种模式，可按自己的使用习惯管理导航。
  • 支持新增分类和网站，也可以隐藏不需要的默认分类或网站，并可随时恢复。
  • 自定义内容保存在当前浏览器，不会修改网站提供的默认导航配置。

Hero 展示图

  • 新增 Hero 图片卡片样式开关，可一键开启或关闭圆角、边框和阴影，适配不同风格的展示图。
  • 修复云端默认展示图在部分浏览器或旧版本设置下无法正常显示的问题；加载较慢时会先收起图片区域，但不会中断正在进行的加载，成功后自动恢复显示。
  • 支持云端默认展示图、自定义图片链接、本地图片和关闭展示四种方式。
  • 新增 16:9、4:3、1:1、最大比例和自定义尺寸，可根据页面布局自由调整展示效果。
  • 修复云端默认展示图不显示、本地图片无法正常选择，以及切换图片比例后视觉没有变化的问题。
  • 优化桌面端 Hero 图片位置与移动端适配，图片加载较慢时提供加载占位，减少页面突变。

搜索与导航

  • 站内搜索支持网站名称、分类名称和域名匹配，无匹配结果时可直接使用搜索引擎继续搜索。
  • 支持多种搜索引擎快速切换，并自动记住用户选择。
  • 修复左侧分类导航跳转不准确、连续点击后失效以及多个分类同时高亮的问题。
  • 完善桌面端与移动端分类导航，让长页面浏览和快速定位更顺畅。

备份与使用体验

  • 新增 JSON 数据导入与导出，可备份自定义导航、Hero 展示图、主题和搜索偏好。
  • 新增深色、浅色、跟随系统和多套主题色，并记住当前浏览器的个性化设置。
  • 优化右上角设置与数据备份按钮，以及 SSL、AI 聊天、回到顶部等快捷操作的视觉样式。
  • 优化站点图标加载、首屏骨架占位、键盘操作和移动端布局，提升日常使用体验。
版本说明：v1.3.6F 重点修复云端默认展示图的加载与恢复问题：兼容旧版本遗留的隐藏状态，慢速加载不再被提前中断，并优化图片请求兼容性。继续保持单 HTML 部署。
